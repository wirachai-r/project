# Health Icons

The `outline-24px/` directory contains the SVG files used by `SymptomIcon`.

- Filenames match the component names from the frontend registry, for example
  `Fever.svg`, `Coughing.svg`, and `IntestinalPain.svg`.
- Keep the API value unchanged (`health:Fever`, `health:Coughing`, etc.).
- SVG is preferred over PNG so icons remain sharp and can inherit app colors.
